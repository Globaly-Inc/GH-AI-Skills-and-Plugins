# Research Areas (3 consolidated)

Cover all three. Default to researching them yourself, one at a time. **Cap ≤6 high-quality sources per area.**
Record distilled notes only — `claim · source(url) · date · confidence` — never raw search dumps. Prefer
primary/official sources for decision-driving claims; treat snippets and repeated secondary articles as leads,
not evidence.

Only spawn a single subagent for an area if it's genuinely too large for one pass (e.g. 10+ competitors) — and
have it return distilled notes, not raw context.

---

## Area 1 — Market & Category
- **Sizing:** TAM (top-down from industry/analyst data) → SAM (segment × geography) → SOM (obtainable in 1–3
  yrs, bottom-up: target accounts × ACV). State assumptions; reconcile top-down vs bottom-up.
- **Demand signals:** search/growth trends, funding into the space, willingness to pay (price points users
  already pay for the status quo).
- **Category:** existing category (compete on execution) vs new category (category design — name it + the
  "from → to" narrative). Pick one with evidence.
- **Trends & regulatory:** key tailwinds/headwinds and any compliance constraints by geography.
- Prefer: analyst reports, filings, government/industry statistics, official category framing.

## Area 2 — Competitors
- Direct + indirect competitors + the status-quo workaround (spreadsheet, manual, nothing).
- For each: features, pricing/packaging, positioning/messaging, target segment, traction signals.
- Prefer: official product/pricing pages, docs, changelogs.

## Area 3 — Voice-of-Customer weaknesses
- Mine real user complaints: **G2, Capterra, Trustpilot, app stores, Reddit, Hacker News, forums**.
- Cluster into themes; quote 1–2 representative verbatims (cited) per theme; count independent mentions.
- **Pattern rule:** a weakness counts as a pattern only with **≥3 independent user mentions**; else "anecdotal".
- These weaknesses are the wedge — where GlobalyHub can win.

---

## Evidence note shape
```text
Claim · Source(url) · Type(official|review|forum|news|analysis) · Date · Confidence(H/M/L) · Limitation
```
If a source can't be verified or is paywalled/unread, say so and lower confidence. Don't fabricate URLs.
